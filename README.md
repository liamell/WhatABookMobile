WhatABook – App Móvil

Aplicación móvil para explorar, buscar y comprar libros de manera rápida, organizada y accesible. WhatABook es una app diseñada para que los usuarios
puedan descubrir libros, leer sus detalles, agregar productos al carrito y gestionar sus compras de una forma intuitiva y cómoda. Está creada con Kotlin y 
Jetpack Compose, y ofrece funciones modernas como navegación fluida, almacenamiento local/remoto y vista por categorías.
